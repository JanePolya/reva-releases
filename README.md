# REVA for Windows

Official Windows downloads: [REVA 1.0.2](https://github.com/JanePolya/reva-releases/releases/tag/v1.0.2).

Product website: https://revalizer.com/reva/

Install the update over your existing REVA. Your lifetime or valid monthly Pro activation stays in %LOCALAPPDATA%\REVA; no new purchase is required. Updates remember the chosen installation folder. Monthly subscriptions retain their paid period and periodic online refresh requirements.

See Releases for changes, the installer, and SHA256SUMS.txt. Windows 10/11 x64. The installer is currently unsigned.

This repository contains binary downloads and documentation only.
