# REVA for Windows

Official binary downloads: https://github.com/JanePolya/reva-releases/releases/tag/v1.0.1

REVA 1.0.1 for Windows 10/11 x64.

- Activate Pro with a signed license key or an authorized giveaway code.
- Existing lifetime and monthly Pro activation survives updates. No new purchase is required.
- The installer shows the destination folder and lets you choose it; updates remember the previous folder.
- Refreshed graphite, ivory and coral interface with colored defaults for every visualizer. Saved custom palettes are preserved.
- Particle Flow adds an inward-emitting reactive ring, particles from spectrum bar peaks and particles from a filled waveform contour.
- Switching visualizer variants keeps each variant's own settings.

Download RevaSetup-1.0.1.exe below, then install over your existing REVA. Your license is stored separately in %LOCALAPPDATA%\REVA. Monthly subscriptions continue to require periodic online refresh within the paid period.
